A post is a markdown file with a few extras. Paragraphs are plain text, with **bold**, *italic*, `code` and [links to other pages](/support) or [anywhere else](https://www.apple.com/macos/).

## A section heading

Sections are `##`, and smaller ones are `###`. The text keeps to a reading width, about the width of the guide on the support page.

### A smaller heading

- A list for things that have no order
- Each item a line or two
- No more than that

1. A numbered list for steps
2. Like the guide's

> A quote, for a line worth stopping on.
